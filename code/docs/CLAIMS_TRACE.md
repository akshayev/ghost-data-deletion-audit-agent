# Claims trace

Every factual claim in `README.md`, `code/docs/ARCHITECTURE.md` and `code/docs/DECISIONS.md`, mapped to the code or test that backs it. Evidence is written `path:Symbol` (a function, class, method or constant defined in that file) or `path::test_name`; `code/tests/test_claims_trace.py` fails if any cited file or symbol does not exist. Numbers in those documents are not listed: they are generated (`code/evaluation/report_numbers.py` → `numbers.json` → `code/docs/render.py`, which refuses to write a document with an unresolved key).

Audit result (P12): claims without code were removed or reworded. Changed during the audit: "with no key the default mode is deterministic" (now: the default replays agent decisions offline, `config.py:resolve_mode`); "one ground-truth check per screenshot" (now: one extraction test plus ten per-screen tests); the OCR misreads in DECISIONS #12 are design-time observations (tesseract is not a dependency), stated as such.
